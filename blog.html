My First Days Learning JavaScript

A few days ago, I started learning JavaScript, and it has been a fun experience so far. At first, I thought coding would be very difficult, but once I started learning the basics, it became interesting. One of the first things I learned was how to use `console.log()` to print messages. I also learned about variables and simple functions. Sometimes my code didn't work because of small mistakes, like forgetting a bracket or misspelling a word, but fixing those mistakes helped me learn. The best part is seeing my code actually do something. Even making a simple button work feels exciting. Although I still have a lot to learn, I am enjoying the process and looking forward to building bigger projects in the future. Learning JavaScript has shown me that making mistakes is a normal part of coding, and every mistake teaches something new.
